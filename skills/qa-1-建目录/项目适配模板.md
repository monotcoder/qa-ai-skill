# 项目适配

这个文件是**这个项目自己的**。skill 升级不会碰它。

skill 规定"查什么"和红线；"怎么做"写在这里。
每个 skill 开始前都先读它；做的过程中踩到新坑，往这里补一条。

## 不能适配掉的四条

这四条对任何项目都一样，不准因为"这个项目特殊"就改：

1. `用例/` 里不准出现任何选择器
2. 判定必须三档：通过 / 失败 / 说不准
3. 走不通必须上报，不准自己换条路把事做成
4. 禁点清单是第一优先级

## 名字怎么起

- 目录和文件名都用中文，每一层都是；只有工具认死的名字、后缀和 npm 命令名用英文
- 项目是 git 仓库的：设了 `core.quotepath false`，中文文件名才不会显示成 `\346\265...`（不是 git 仓库的删掉这一行）
- `项目适配.md`、`用例清单.md` 这两个名字固定，不准改
