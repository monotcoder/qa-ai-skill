# 导出用例 · 按团队的格式交给别人看

只在用户要把用例给别人看、交给团队、导进用例平台时读这个文件。
用户可能说：「导出用例」「把用例发给开发看」「按我们的模板出一份」「导进禅道」。

**每个团队的格式都不一样**：有的要 Excel，有的要飞书表格、禅道或 TestLink 的导入文件，
有的有自己的模板，列名、优先级的叫法、步骤怎么写都不同。**不要猜，第一次先问清楚，问完记下来，下次直接按这个出。**

## 1. 先看 `项目适配.md` 里有没有「用例导出」那一段

- 有：照着出，不用再问。出之前说一句「按上次定的格式：XX，要改就说」
- 没有：按第 2 步问

## 2. 第一次：问这几件事，一次问完

1. **给谁看、用来干什么**：开发自测、评审会、交给测试主管、导进用例平台……
   这决定要不要带「预期来源」「最近判定」这些我们自己的列
2. **什么格式**：Excel / CSV / 飞书或钉钉表格 / 禅道、TestLink、TAPD 这类平台的导入文件 / Word / Markdown / 思维导图
3. **有没有团队模板**：有的话**请他把模板文件放进项目里**（比如 `用例/导出/模板.xlsx`），或者把表头那一行贴过来。
   没有模板就用第 4 步的默认列
4. **出哪些**：默认只出「审了没」是「已确认」的。他要连没审的一起出，也可以，但没审的必须标出来（见第 5 步）

## 3. 有模板：先对字段，给他看过再出

读模板的表头，跟我们的字段一一对上，整理成对照表给他过目：

```markdown
| 模板的列 | 从哪来 | 怎么填 |
| --- | --- | --- |
| 用例编号 | 编号 | 原样：批次-01 |
| 所属模块 | 流程 | 原样 |
| 用例标题 | 一句话 | 原样 |
| 前置条件 | 前置 + 前置数据 | 两段合在一格，中间换行 |
| 操作步骤 | 步骤 | 一格里编号写：1. 进入生产批次 2. …，每步换行 |
| 预期结果 | 预期 | 原样 |
| 优先级 | 范围 | 冒烟 → P1，全量 → P2（**他定的，不是你定的**） |
| 用例类型 | （我们没有） | 空着，或者问他填什么 |
| 备注 | 预期来源、审了没 | 见第 5 步 |
```

- **我们没有、模板要的**（比如「用例类型」「设计人」）：列出来问他怎么填，不要编
- **我们有、模板没有的**（比如「预期来源」）：问他要不要加一列；不加的，要紧的信息放进备注
- 平台导入文件（禅道、TestLink……）：**按那个平台官方文档里的导入格式**，用他那个版本的文档，别凭记忆。
  先导一两条试试，他在平台上看过没问题再全导

## 4. 没有模板：默认这几列

`编号 · 模块 · 标题 · 前置条件 · 步骤 · 预期结果 · 优先级 · 预期来源 · 审了没 · 最近判定`

格式默认 Excel 能打开的 CSV。**CSV 要带 BOM（UTF-8 with BOM）**，不然 Excel 打开中文是乱码。
要 `.xlsx`、`.docx` 这类要另装工具才能生成的，**先问他能不能装、说清要装什么**，不要自己装。

## 5. 不管什么格式，这几条不能丢

- **没审的、AI 猜的要看得出来**。模板里没有对应的列，就在备注写「预期是 AI 推测，还没确认」。
  别人拿到一份看起来很正式的表，会以为每条预期都是定了的
- **只写业务话**。不导出 `绑定/` 里的页面位置，不出现选择器
- **文件里写明是什么时候、从哪导出的**：表头上面或者第一行备注写
  `导出：QA 流水线 v<版本号> · qa-3-出用例 · <日期> · 共 N 条（已确认 X 条，未审 Y 条）`，版本号跟开口第一行一样。
  模板不允许多一行的，写进文件名
- **会让线上留痕迹的用例**（打开一次扫码量 +1），备注里写上，别人照着手测也会留痕迹

## 6. 放在哪

`用例/导出/<日期>-<给谁或什么格式>.<后缀>`，比如 `用例/导出/2026-10-15-评审会.csv`。

**导出的是副本，用例以 `用例/` 里的 yaml 为准。** 不要去改导出的文件；
要改，改 yaml，再导一次。

## 7. 别人改过、发回来了

团队评审常常是别人在表里改了再发回来。**这就是审用例**：

1. 跟 yaml 对比，把改了的每一条列给用户：哪条、原来是什么、改成了什么、谁改的
2. **用户点头的**才改回 yaml，`预期来源` 写 `用户确认 · 评审会 · 2026-10-16`，`审了没` 改成「已确认」
3. 加了新用例的，按我们的编号规则给编号，补进 `用例清单.md`
4. 删了的，问一句是删掉还是先不跑，不要直接删

## 8. 记进 `项目适配.md`

```markdown
## 用例导出

- 给谁：评审会 / 开发自测 / 导进禅道
- 格式：CSV（带 BOM）/ 团队模板 `用例/导出/模板.xlsx` / 禅道导入文件
- 出哪些：只出已确认的 / 全部，未审的在备注里标
- 字段对照：（第 3 步那张表）
- 定于：2026-10-15
```

下次用户说「导出用例」，照这段出，不再问。
